## 3. 상세 설명

### 인트로
> LUMEN(루멘)은 "빛"이라는 뜻입니다.
> 화려한 장식 대신 넉넉한 여백, 큰 상품 이미지, 세리프 포인트 타이포그래피로
> 상품 자체가 빛나도록 설계한 반응형 스킨입니다.
> 의류·잡화·리빙 분야의 1인~소규모 브랜드에 맞췄습니다.

### 특장점 8가지

1. **하나의 디자인, 모든 화면** — 모바일(768px 미만)·태블릿·PC(1024px 이상) 3단계 반응형. PC와 모바일을 따로 관리할 필요가 없습니다.
2. **큰 이미지 중심 레이아웃** — 풀폭 메인 슬라이더, 4:5 비율 상품 이미지, 룩북/에디토리얼 섹션으로 브랜드 무드를 전달합니다.
3. **마우스를 올리면 두 번째 이미지** — 상품 카드에 커서를 올리면 착용컷 등 두 번째 이미지로 전환됩니다.
4. **할인이 한눈에** — 할인율(포인트 컬러)·판매가·소비자가(취소선)·NEW/BEST/SALE 배지·컬러칩을 카드에 표시합니다.
5. **구매에 집중한 상세페이지** — 좌측 갤러리 + 우측 따라오는(sticky) 구매박스, 하단 탭(상세정보/구매안내/리뷰/Q&A), 모바일 하단 고정 구매 버튼.
6. **앱 같은 모바일 내비게이션** — 슬라이드 드로어 카테고리(아코디언) + 하단 고정 탭바(홈/카테고리/검색/마이/장바구니).
7. **파일 하나로 색상·폰트 변경** — `css/lumen.variables.css`에서 브랜드 컬러와 폰트를 바꾸면 전체에 반영됩니다.
8. **섹션 단위 on/off** — 메인의 각 섹션이 주석 블록으로 나뉘어 있어, 필요 없는 섹션은 주석 처리만 하면 됩니다.

## 6. FAQ (10개)

**Q1. PC와 모바일 디자인을 따로 구매해야 하나요?**
A. 아니요. LUMEN은 반응형 스킨이라 하나의 디자인이 PC·태블릿·모바일에 모두 맞춰 표시됩니다.

**Q2. 구매 후 어떻게 적용하나요?**
A. 구매하면 쇼핑몰의 디자인 보관함에 추가됩니다 [확인 필요: 실제 전달 방식]. 보관함에서 "대표 디자인"으로 설정하면 적용됩니다. 자세한 방법은 구매자 매뉴얼에 있습니다.

**Q3. 기존 디자인이 사라지나요?**
A. 아니요. 기존 디자인은 보관함에 그대로 남아 언제든 되돌릴 수 있습니다. 적용 전 기존 디자인 백업을 권장합니다.

**Q4. 미리보기 사진(데모 이미지)도 함께 제공되나요?**
A. [확정 필요] 데모 이미지는 라이선스 문제로 제공되지 않거나 일부만 제공될 수 있습니다. 상품 이미지는 직접 등록하신 이미지로 표시됩니다.

**Q5. 색상과 폰트를 바꿀 수 있나요?**
A. 네. `css/lumen.variables.css` 파일 한 곳에서 색상·폰트를 바꾸면 전체에 적용됩니다.

**Q6. 메인 화면의 섹션을 빼거나 순서를 바꿀 수 있나요?**
A. 네. `index.html`의 섹션이 주석 블록으로 나뉘어 있어 블록 단위로 숨기거나 옮길 수 있습니다.

**Q7. HTML/CSS를 몰라도 사용할 수 있나요?**
A. 로고·배너·상품·카테고리는 관리자 화면에서 바꿀 수 있습니다. 색상·섹션 변경은 매뉴얼의 예시대로 값만 바꾸면 됩니다. 어려우시면 설치 대행 옵션을 이용하세요.

**Q8. 설치나 수정을 대신 해주나요?**
A. 스킨 오류는 무상으로 지원합니다. 설치 대행·디자인 수정은 유상 옵션으로 제공합니다(가격은 상세페이지 참고).

**Q9. 업데이트는 무료인가요?**
A. 스킨 버그 수정 및 카페24 기능 변경 대응 업데이트는 무료입니다. 단, 직접 수정한 파일은 업데이트 시 덮어써질 수 있으니 수정 내역을 따로 보관해 주세요.

**Q10. 한 번 구매하면 여러 쇼핑몰에 쓸 수 있나요?**
A. [확인 필요: 디자인센터 라이선스 정책] 기본적으로 구매한 쇼핑몰 1곳에서 사용하는 것을 원칙으로 합니다.

## 7. 업데이트 정책 (초안)

- **무상 업데이트 대상**: 스킨 자체 버그, 카페24 시스템 변경으로 인한 오류, 주요 브라우저 업데이트 대응
- **주기**: 긴급 버그는 확인 후 가능한 빨리, 정기 개선은 분기 1회 목표
- **공지**: 디자인센터 상품 상세 "업데이트 내역"에 버전·날짜·변경 파일 기록
  - 예: `v1.0.1 (2026-11-xx) — 모바일 탭바 장바구니 수량 배지 위치 수정 / 변경: layout/basic/...`
- **적용 방법**: 변경된 파일 목록을 제공하여 구매자가 필요한 파일만 교체할 수 있게 함 [디자인센터의 업데이트 배포 기능 유무 확인 필요]
- **주의**: 구매자가 직접 수정한 파일은 업데이트 시 덮어써질 수 있음
