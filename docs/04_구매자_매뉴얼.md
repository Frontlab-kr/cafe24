# LUMEN 구매자 매뉴얼

> LUMEN(루멘) 반응형 스킨을 구매해 주셔서 감사합니다.
> 이 매뉴얼은 HTML을 잘 몰라도 따라 할 수 있게 작성했습니다.
> 카페24 관리자 메뉴 이름은 업데이트로 바뀔 수 있습니다. 메뉴가 보이지 않으면 관리자 상단 검색창에서 메뉴명을 검색하세요.

## 1. 스킨 적용하기

1. 카페24 관리자 로그인
2. **디자인(PC/모바일) 관리 > 디자인 보관함**으로 이동
3. 구매한 **LUMEN** 디자인이 목록에 있는지 확인
   - 보이지 않으면: 디자인센터 구매 내역에서 "쇼핑몰에 추가" 상태를 확인하세요.
4. **적용 전 지금 쓰는 디자인을 복사(백업)** 해 두세요. 문제가 생기면 바로 되돌릴 수 있습니다.

> 팁: 바로 대표 디자인으로 바꾸지 말고, 먼저 **미리보기**로 확인한 뒤 적용하세요.

## 2. 대표 디자인 설정

1. 디자인 보관함에서 LUMEN의 **[대표디자인 설정]** 클릭
2. LUMEN은 반응형이므로 PC·모바일에 같은 디자인이 쓰입니다.
   - 모바일 전용 디자인을 따로 쓰고 있었다면, 모바일 쇼핑몰 설정에서 반응형 디자인이 표시되도록 설정을 확인하세요.
3. 쇼핑몰 주소로 접속해 PC와 휴대폰에서 각각 확인

## 3. 로고·배너 교체

### 로고
- 권장 크기: 가로 300px 이하, 높이 60px 내외, **투명 배경 PNG 또는 SVG**
- 방법 A (관리자): 디자인 편집 > 로고 영역 이미지 교체 [메뉴 위치는 관리자 버전에 따라 다를 수 있음]
- 방법 B (파일): FTP 또는 스마트디자인 편집창의 `img/logo.png`(예시 경로)를 같은 이름으로 덮어쓰기

### 메인 비주얼 슬라이더
- 권장 비율: PC 16:7 (예: 1920×840), 모바일 4:5 (예: 1080×1350)
- PC용·모바일용 이미지를 각각 준비하면 모바일에서 얼굴/상품이 잘리지 않습니다.
- `index.html`의 `MAIN VISUAL` 블록에서 이미지 경로·링크·문구를 수정하세요.

### 배너 2분할
- 권장 비율 1:1 또는 4:5, 같은 크기 2장
- `index.html`의 `BANNER 2COL` 블록에서 수정

### 상단 띠배너(공지)
- `index.html` 또는 공통 레이아웃의 `TOP NOTICE` 블록에서 문구 수정
- 사용하지 않으면 해당 블록을 주석 처리

> 이미지 용량은 장당 300KB 이하(WebP/JPG 압축 권장). 큰 이미지는 모바일 로딩을 느리게 합니다.

## 4. 색상·폰트 변경

파일: **`css/lumen.variables.css`** — 이 파일 하나만 수정하면 전체에 반영됩니다.

```css
:root {
  --c-ink: #141414;      /* 기본 글자색 */
  --c-sub: #6B6B6B;      /* 보조 글자색(설명, 날짜) */
  --c-line: #E6E4E0;     /* 구분선 */
  --c-bg: #FFFFFF;       /* 기본 배경 */
  --c-bg-soft: #F6F4F0;  /* 연한 배경(섹션 구분) */
  --c-accent: #B5532F;   /* 포인트: 할인율, SALE 배지, 강조 */

  --font-base: "Pretendard", -apple-system, "Apple SD Gothic Neo", sans-serif;
  --font-display: "Cormorant Garamond", "Noto Serif KR", serif; /* 영문 헤드라인 */
}
```

### 예시: 포인트 컬러를 네이비로
```css
--c-accent: #1F3A5F;
```

### 추천 조합
| 무드 | --c-accent | --c-bg-soft |
|---|---|---|
| 기본(테라코타) | #B5532F | #F6F4F0 |
| 올리브 | #5B6B3A | #F3F3EC |
| 네이비 | #1F3A5F | #F2F4F7 |
| 버건디 | #7A2E3A | #F7F2F2 |

> 글자색과 배경색의 대비가 너무 낮으면 읽기 어렵습니다. 밝은 포인트 컬러(노랑·민트 등)는 글자색으로 쓰지 마세요.

### 폰트 변경
1. 사용할 웹폰트를 불러옵니다(무료 상업용 폰트 권장: 예) Pretendard, Noto Sans KR 등 — **라이선스는 직접 확인**).
2. `--font-base` 또는 `--font-display`의 첫 번째 이름을 바꿉니다.
   ```css
   --font-base: "Noto Sans KR", sans-serif;
   ```

## 5. 메인 섹션 켜기/끄기

파일: **`index.html`** — 각 섹션은 아래처럼 시작/끝 주석으로 감싸져 있습니다.

```html
<!-- [LUMEN] SECTION: NEW ARRIVALS START -->
<section class="lm-section lm-new"> ... </section>
<!-- [LUMEN] SECTION: NEW ARRIVALS END -->
```

### 섹션 숨기기
START와 END 사이 전체를 HTML 주석으로 감쌉니다.
```html
<!-- [LUMEN] SECTION: INSTAGRAM START
<section class="lm-section lm-insta"> ... </section>
[LUMEN] SECTION: INSTAGRAM END -->
```
> 주의: 블록 안에 다른 주석(`<!-- -->`)이 있으면 주석이 중간에 끝납니다. 그럴 때는 블록을 통째로 잘라내 메모장에 보관하세요.

### 섹션 순서 바꾸기
START~END 블록을 통째로 잘라 원하는 위치에 붙여 넣습니다.

### 섹션 목록
| 순서 | 섹션 | 비고 |
|---|---|---|
| 1 | MAIN VISUAL | 풀폭 슬라이더 |
| 2 | CATEGORY SHORTCUT | 카테고리 바로가기 |
| 3 | NEW ARRIVALS | 관리자 메인진열 1 연동 (`product_listmain_1`) |
| 4 | BANNER 2COL | 2분할 배너 |
| 5 | BEST | 탭형 베스트 |
| 6 | LOOKBOOK | 에디토리얼 |
| 7 | INSTAGRAM | 인스타그램 그리드 |
| 8 | NEWSLETTER | 뉴스레터 신청 |

> `index.html`에서 `[SECTION 01] START` ~ `[SECTION 08] END` 주석으로 구분되어 있습니다. BEST 탭은 메인진열 2·3·4를 사용합니다.

### 상품 진열 바꾸기
NEW ARRIVALS·BEST에 나오는 상품은 관리자 **상품 관리 > 메인 진열**에서 관리합니다. 코드를 수정하지 않아도 됩니다.

## 6. 카테고리 메뉴

- 관리자 **상품 관리 > 상품 분류 관리**에서 대/중분류를 만들면 PC 상단 메뉴와 모바일 드로어에 자동 표시됩니다.
- 중분류는 모바일 드로어에서 아코디언(펼치기)으로 보입니다.
- 메뉴가 너무 많으면 PC 헤더가 줄바꿈될 수 있습니다 → 대분류는 6~8개 이내 권장.
- 특정 분류를 메뉴에서 숨기려면 분류 설정의 "표시 상태"를 조정하세요.

## 7. 모바일 하단 탭바

- 구성: 홈 / 카테고리 / 검색 / 마이 / 장바구니(수량 배지)
- 768px 미만 화면에서만 보입니다.
- 아이콘·링크 수정: `layout/basic/header.html`의 `<nav class="lm-tabbar">` 블록
- 끄기: `lm-tabbar` 블록 주석 처리 + `css/lumen.variables.css`의 `--tabbar-h: 60px;`를 `0px`로 변경
- 상품 상세에서는 하단 고정 구매 버튼과 겹치지 않도록 탭바가 자동으로 숨겨집니다 (`js/lumen.js` 처리).

## 8. 자주 묻는 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 적용했는데 예전 디자인이 보여요 | 대표 디자인 설정 확인 → 브라우저 강력 새로고침(Ctrl+Shift+R) 또는 시크릿 창 확인 |
| 색상을 바꿨는데 반영이 안 돼요 | 수정한 파일이 대표 디자인의 파일인지 확인, 저장 후 캐시 새로고침, 세미콜론(`;`) 누락 확인 |
| 모바일에서 레이아웃이 깨져요 | 직접 넣은 이미지/표의 고정 너비(`width="900"` 등) 제거, 상세 설명 이미지는 가로 860px 이하 권장 |
| 상품 이미지가 늘어나/잘려 보여요 | LUMEN은 4:5 비율 기준. 상품 이미지를 4:5(예: 1000×1250)로 등록 |
| hover 시 두 번째 이미지가 안 나와요 | 상품에 추가 이미지가 등록되어 있는지 확인 |
| 할인율이 안 보여요 | 상품의 소비자가(정가)가 판매가보다 높게 입력되어 있는지 확인 |
| 메인 섹션이 통째로 사라졌어요 | 주석을 열기만 하고 닫지 않았는지(`-->` 누락) 확인 |
| 로고가 흐려요 | 표시 크기의 2배 해상도 이미지 또는 SVG 사용 |
| 폰트가 바뀌지 않아요 | 웹폰트 불러오기 코드가 있는지, 폰트 이름 철자·따옴표 확인 |
| 푸터 회사 정보가 비어 있어요 | 관리자 **쇼핑몰 설정 > 기본 정보**에 상호·대표자·사업자번호·통신판매업번호 입력 |
| 그 외 오류 | 판매자에게 문의: 쇼핑몰 주소, 증상 캡처, 기기/브라우저, 수정한 파일 목록을 함께 보내 주세요 |
