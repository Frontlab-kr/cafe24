# LUMEN 카페24 디자인센터 입점 로드맵

> 목표: 반응형 스킨 **LUMEN**을 카페24 디자인센터(https://d.cafe24.com)에 등록해 판매를 시작한다.
> 표기 규칙: **[확인 필요]** = 공식 문서로 검증하지 못한 내용. 가입·등록 화면에서 직접 확인 후 이 문서를 갱신할 것.

---

## 0. 한눈에 보기

```
판매자(리셀러) 가입 → 샘플 쇼핑몰 준비 → 스킨 업로드(FTP/스마트디자인)
→ 디자인 보관함 등록 → 디자인센터 상품 등록 → 심사 → 판매 → CS·업데이트
```

| 단계 | 핵심 산출물 | 담당 |
|---|---|---|
| 1. 가입·심사 | 판매자 계정, 정산 정보 | 사용자 |
| 2. 샘플몰 | 데모용 카페24 쇼핑몰 + 샘플 상품/이미지 | 사용자 + repo |
| 3. 업로드 | LUMEN 스킨 파일 반영 | repo → 사용자 |
| 4. 상품 등록 | 상세페이지, 썸네일, 가격 | `02_상품등록_카피.md`, `03_가격_경쟁전략.md` |
| 5. 심사 | 반려 대응 | `05_QA_체크리스트.md` |
| 6. 판매 후 | CS, 업데이트 | `04_구매자_매뉴얼.md` |

## 1. 판매자(리셀러/파트너) 가입·심사

### 확인된 내용 (출처 있음)
- 카페24 리셀러 안내 페이지(https://reseller.cafe24.com/product/product_design.php)는 **리셀러로 가입하면 디자인센터를 통해 디자인을 판매할 수 있고, 판매가는 판매자가 직접 정하며, 사업자등록증이 없어도 신청 가능**하다는 취지로 안내한다. (검색 결과 요약 기준. 샌드박스에서 원문 직접 열람 불가 → 가입 시 원문 재확인 권장)
- 디자인센터는 중개 시스템이며 등록 내용에 대한 책임은 개별 판매자에게 있다는 취지의 문구가 있다. (https://d.cafe24.com/designer/designer_main, 검색 요약 기준)

### 확인 필요
- [확인 필요] 판매 수수료율 / 수익 배분 비율 — **어떤 수치도 추정해서 쓰지 말 것.** 판매자 약관(https://d.cafe24.com/customer/customer_terms_seller)에서 직접 확인.
- [확인 필요] 정산 주기(월 1회 등), 최소 정산 금액, 원천징수(개인 3.3% 여부) 처리 방식.
- [확인 필요] 가입 후 별도 "판매자 심사"가 있는지, 아니면 상품(디자인) 단위 심사만 있는지.
- [확인 필요] 가입비·연회비 유무.

### 진행 순서
1. 카페24 통합 계정(회원) 생성
2. 리셀러 / 디자인센터 판매자 신청 (reseller.cafe24.com 또는 d.cafe24.com 판매자 메뉴) [확인 필요: 정확한 메뉴명]
3. 판매자 정보, 정산 정보 입력 → 약관 동의 (**약관 전문을 PDF/캡처로 보관**)
4. 승인 알림 수신

### 통신판매업 신고 — [확인 필요]
- 카페24 고객지원 문서는 **쇼핑몰 운영자**에게 온라인 판매 전 통신판매업 신고(정부24 또는 관할 구청, 사업자등록증 사본·에스크로 가입 증빙 등)를 안내한다. (https://support.cafe24.com/hc/ko/articles/7668252096793, 검색 요약 기준)
- 단, 이것은 "쇼핑몰을 직접 운영하는 사람" 기준이다. **디자인센터라는 중개 플랫폼에서 디지털 상품(스킨)만 파는 판매자에게 통신판매업 신고가 필요한지는 확인 필요.** 판매 규모가 커지면 사업자등록 + 통신판매업 신고를 함께 검토할 것(세무사/관할 구청 문의).
- 데모용 샘플몰은 실제 판매를 하지 않으므로 결제·통신판매업과 무관하게 운영 가능할 것으로 보이나 [확인 필요].

## 3. 샘플(데모) 쇼핑몰 만들기

1. 카페24에서 **무료 쇼핑몰 신규 생성** (판매자 계정과 같은 ID 권장)
2. 기본 설정: 쇼핑몰명 "LUMEN DEMO", 상호/고객센터는 데모용 표기
3. 카테고리 구성(예): NEW / OUTER / TOP / BOTTOM / DRESS / BAG & SHOES / LIVING / SALE
4. 샘플 상품 최소 24개 등록 — 아래 케이스 포함 (QA에도 그대로 사용)
   - 옵션 상품(색상×사이즈), 단일 상품, 품절 상품, 할인 상품, 적립금 설정 상품, 이미지 1장만 있는 상품, 이미지 없는 상품
5. 게시판: 공지, 상품후기, 상품 Q&A에 샘플 글 3개 이상
6. **이미지 라이선스**: 상업적 이용·재배포가 허용된 이미지만 사용 (05 문서 7장 참고). 스킨 패키지에 포함되는 이미지는 특히 주의.

## 4. 스킨 업로드 (FTP / 스마트디자인)

1. 관리자 > 디자인(PC/모바일) 관리 > **디자인 추가**로 기본 반응형 디자인을 하나 추가 (LUMEN의 바탕) [확인 필요: 현재 관리자 메뉴명]
2. FTP 계정 확인 — 카페24 고객센터 FTP 섹션 참고: https://support.cafe24.com/hc/ko/sections/7695326679193
3. FTP 클라이언트(FileZilla 등)로 접속 → 해당 디자인의 스킨 폴더(예: `/skinN/`) [확인 필요: 폴더 구조] 에 LUMEN 파일 업로드
   - `css/lumen.variables.css` (토큰), `index.html` (메인 섹션 주석 블록), 공통 레이아웃, 상품/주문/회원 페이지
4. 스마트디자인 편집창에서 미리보기 → 오류 모듈 수정
5. 업로드 전후로 **디자인 백업**(보관함 복사본) 유지

> 업로드 시 주의: 카페24 기본 모듈(`module="..."`) 및 변수(`{$...}`)를 삭제하면 기능이 깨진다. 구매자가 받아도 동작하도록 외부 경로 하드코딩 금지, 이미지 경로는 상대경로.

## 5. 디자인 보관함 → 판매 디자인 지정

1. 관리자 > 디자인 보관함에서 LUMEN 디자인 확인
2. 데모몰의 **대표 디자인**으로 설정 (구매 예정자가 보는 미리보기 URL이 됨)
3. 판매용으로 지정/등록하는 연동 절차 [확인 필요: 디자인센터 판매자 페이지에서 "내 쇼핑몰 디자인 불러오기" 방식인지, 파일 업로드 방식인지]
