## 1. 시장 가격대 조사

### 확인된 사실
- 디자인센터 판매가는 **판매자가 직접 정한다** (https://reseller.cafe24.com/product/product_design.php, 검색 결과 요약 기준).
- 외주 제작 업체들은 "스킨은 디자인센터에서 별도 구매, 가격·디자인이 다양함"이라고 안내하며, 스킨 구매+세팅 패키지를 수십만~백만 원대에 판매한다.
  - 예: 기본형 패키지 66만 원(스킨 비용 포함) / 스탠다드 165만 원(VAT 포함, 스킨 포함) — 출처: kmong 카페24 제작 서비스 검색 결과 요약(개별 페이지 미확인). **스킨 단품 가격이 아님에 주의.**

### 확인 필요
- [확인 필요] 디자인센터 반응형 스킨 단품 가격대(하위/중위/상위)
- [확인 필요] 판매 수수료율 → **실수령액 = 판매가 − 수수료 − 세금** 계산에 필수
- [확인 필요] 무료 스킨 비중, 할인 이벤트 관행

### 시장 조사 방법 (사용자가 직접, 1~2시간)
1. d.cafe24.com > 반응형 필터 > 업종 "의류/패션", "리빙" 선택
2. 인기순·최신순 상위 각 20개 기록
3. 아래 표 채우기

## 2. 가격 설정 원칙 (조사 후 적용)

| 구분 | 공식(가설) | 이유 |
|---|---|---|
| 런칭가 | 시장 P50 × 0.7~0.8 | 리뷰 0개 신규 스킨의 진입 장벽 보완 |
| 정가 | 시장 P50 ~ P75 사이 | 리뷰 10개+ 확보 후 전환 |
| 런칭가 기간 | 오픈 후 4~6주 또는 판매 20건 도달 시 종료 | 조기 구매자에게 명분 제공 ("런칭 기념가") |

- 할인은 "정가 대비 몇 % 할인" 형태로 표기 → 정가를 먼저 정할 것
- 디자인센터에서 할인가 표시 기능 유무 [확인 필요]. 없으면 가격 변경 + 상세페이지 문구로 처리.

## 3. 판매 옵션 구성

| 옵션 | 포함 내용 | 가격(가설) | 판매 채널 |
|---|---|---|---|
| **A. 스킨만** | LUMEN 스킨 + 매뉴얼 + 무상 업데이트 | 시장 조사 후 결정 | 디자인센터 |
| **B. 설치 대행** | A + 대표 디자인 적용, 로고·메인 배너 3장·카테고리 세팅, 색상 1회 변경 | 스킨가 + α [확인 필요] | 디자인센터 부가 옵션 가능 여부 [확인 필요], 불가 시 별도 안내 |
| **C. 커스텀 패키지** | B + 메인 섹션 구성 변경, 상세페이지 템플릿 1종, 수정 2회 | 견적제 | 별도 견적 (이메일) |

- 설치 대행·커스텀을 디자인센터 밖에서 받는 것이 정책상 허용되는지 **약관 확인 필수** [확인 필요]
- 작업 범위·수정 횟수·납기(B: 영업일 3일, C: 영업일 7~14일)를 문서화해 분쟁 방지

## 4. 경쟁 차별화

| 축 | LUMEN의 포지션 | 상세페이지에서 보여줄 증거 |
|---|---|---|
| 속도 | 가벼운 미니멀 구조 | Lighthouse 모바일 점수 캡처 (05 문서) |
| 수정 쉬움 | 변수 파일 1개 + 섹션 주석 블록 | 색상 3종 변경 전후 캡처, 30초 GIF |
| 모바일 UX | 하단 탭바 + 드로어 + 고정 구매버튼 | 모바일 화면 연속 캡처 |
| 무드 | 세리프 포인트, 여백, 4:5 이미지 | 룩북 섹션 풀 캡처 |
| 신뢰 | 업데이트 내역 공개, 응답 기준 명시 | 변경 로그, CS 정책 |

- 경쟁 스킨을 실명으로 비교하지 않는다.
- 1장 조사표에서 "최근 업데이트가 오래된 스킨", "모바일 탭바 없는 스킨" 비율을 확인하면 차별 포인트를 수치로 말할 수 있다.

## 5. 리뷰 확보 전략

1. **런칭가** 자체를 첫 리뷰 유인으로 사용
2. 구매 후 7일 차 안내 메일(가능한 경우): 설치 잘 됐는지 확인 + 리뷰 요청 (보상 조건부 리뷰는 플랫폼 정책 확인 후 [확인 필요])
3. 빠른 CS 응답 → 만족 리뷰로 이어지게
4. 지인·기존 고객에게 **정상 구매** 후 사용 요청 (가짜 리뷰·자작 리뷰 금지 — 플랫폼 제재 위험)
5. 실제 적용 쇼핑몰 사례(동의받은 경우)를 상세페이지 "적용 사례"에 추가
