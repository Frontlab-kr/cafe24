## 3. 페이지별

## 5. 접근성

- [ ] 모든 이미지 `alt` (장식 이미지는 `alt=""`)
- [ ] 키보드만으로 메뉴·드로어·옵션 선택·장바구니 담기 가능, 포커스 표시 보임
- [ ] 아이콘 버튼(검색/장바구니/닫기/햄버거)에 `aria-label`
- [ ] 텍스트 대비 4.5:1 이상 — `--c-sub #6B6B6B` on 흰 배경 확인, accent 위 흰 글자 확인
- [ ] 슬라이더 일시정지 가능, 자동재생 과도하지 않음
- [ ] 터치 타깃 최소 44×44px (탭바, 수량 버튼, 닫기)
- [ ] `lang="ko"`, 제목 계층(h1→h2) 논리적
- [ ] `prefers-reduced-motion` 시 애니메이션 최소화

## 7. 저작권 · 라이선스 (심사·분쟁 핵심)

> **판매용 스킨에 들어가는 샘플 이미지는 반드시 상업용 + 재배포(템플릿/디지털 상품 포함) 허용 라이선스여야 한다.**
> 일반 스톡 "표준 라이선스"는 템플릿·테마 내 재배포를 금지하는 경우가 많다 → 각 사이트 약관에서 "templates / themes / resale" 조항 확인.

### 이미지
- [ ] 데모몰·상세페이지·썸네일에 쓴 모든 이미지의 출처·라이선스 목록 작성 (파일명 / 출처 URL / 라이선스 / 구매일)
- [ ] 스킨 패키지에 **포함되는** 이미지 → 재배포 허용 확인, 불확실하면 회색 플레이스홀더로 교체
- [ ] 데모에만 쓰는 이미지 → 상업적 이용(광고·판매 홍보) 허용 확인
- [ ] 인물 사진: 모델 릴리즈(초상권) 확인
- [ ] 실존 브랜드 로고·상표·제품 사진 사용 금지
- [ ] 아이콘: 라이선스 확인 (예: MIT/ISC 등 상업 이용 가능 라이선스, 고지 필요 여부)

### 폰트
- [ ] Pretendard — SIL Open Font License 1.1 (상업 이용·임베딩 가능, 폰트 파일 단독 판매 금지) → 라이선스 고지 포함
- [ ] Cormorant Garamond — SIL Open Font License 1.1 (Google Fonts) → 고지 포함
- [ ] Noto Serif KR — SIL Open Font License 1.1 → 고지 포함
- [ ] 위 라이선스는 각 공식 배포처에서 최종 재확인
- [ ] 유료 폰트를 스킨에 포함하지 않음 (구매자 PC에 없는 폰트 사용 금지)

### 코드

- [ ] 타 스킨·타 사이트 코드 복사 없음
